# 运营后台源码

本目录是 TOPUYI 运营后台。小程序源码位于仓库根目录，本目录已从微信小程序打包范围中排除。

## 本地构建

使用 Node.js 22.13 或更新版本，在本目录执行：

```sh
npm ci
node lib/editor.test.mjs
node deploy-cn/build.mjs
```

腾讯云部署方式见 deploy-cn/README.md。云函数源码在 server/ops-functions 中。商品数据、上传素材、账号凭据和本机备份不包含在仓库中。

独立检出到其他路径时，将 TOPUYI_MINI_PROJECT 设置为小程序源码目录。部署 shop-service 时必须开启云端安装 package.json 依赖。
