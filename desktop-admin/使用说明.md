# TOPUYI 电脑端首页装修

双击同文件夹的“打开装修后台.cmd”。在电脑浏览器中打开 `http://localhost:5188/local`。

1. 左侧选择模块；拖动排序，也可使用右侧“上移”和“下移”。
2. 右侧点击“点击或拖入图片”，选择电脑上的 JPG、PNG 或 WebP 图片，单张最大 8MB。视频支持 MP4 和 WebM，单个最大 30MB。
3. 编辑标题、说明、跳转入口；在“样式设置”调整颜色、高度、间距和列数。
4. 中间即时预览。轮播图底部圆点可切换图片，视频可播放。预览跳转为展示，不会进入实际商城。
5. 点击“保存草稿”，图片、视频及布局保留在当前浏览器。关闭再打开会恢复。
6. “我的模板”可保存多套页面。用“导出模板”备份，或交给同事在同版本后台导入。模板文件包含素材。

## 同步到开发版小程序

1. 电脑后台右上角点击“同步到开发版”。
2. 点击“检查连接”。如提示登录过期，双击同目录的“登录云开发.cmd”，使用 TOPUYI 对应账号授权后重新检查。
3. 点击“同步当前页面”，等待图片、视频和配置上传完成，再复制弹窗中的预览码。
4. 用微信开发者工具打开 `D:\Project\mini\mini_topuyi`，重新编译。开发版首页点击“连接电脑后台”，粘贴预览码。
5. 以后运营再次同步后，在开发版首页下拉刷新。首次连接之后不需要每次填写预览码。

“保存草稿”仍只保存本机内容；“同步当前页面”才将完整页面上传到云端开发预览区域。电脑端草稿不会覆盖小程序的“本机装修”草稿；如在本机装修预览中，重新连接电脑后台可返回云端预览。

本次只接入开发版/体验版，不提供正式版发布。独立集合为 `topuyi_home_preview_v1`，云函数为 `topuyi-home-preview-v1`，素材目录为 `topuyi/home-preview/v1/`。集合仅管理员可读写，函数凭预览码只读配置。登录凭据只在本机服务端使用，不发送到网页或小程序。

商品卡片仍为手动配置的展示内容，未关联真实商品库。现有价格、库存、订单、支付接口均未改动。开发预览不是正式发布；未来正式版接入需另行开发和发布小程序。

请固定使用同一浏览器及地址。清理浏览器网站数据会删除本机草稿和模板；先导出备份。普通模式使用，避免无痕窗口。`localhost` 地址只能在运行后台的电脑上使用。其他电脑需要本后台、Node.js、CloudBase CLI 及小程序项目依赖，并以有权限的云账号登录；项目位置可通过 `TOPUYI_MINI_PROJECT` 环境变量设置。更换电脑前导出模板备份。
