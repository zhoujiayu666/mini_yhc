# TOPUYI 在线运营后台

运营同事使用在线地址和运营账号登录，无需安装开发工具或获取腾讯云管理员凭据。

## 操作流程

1. 登录后在左侧选择模块，拖动调整顺序。
2. 右侧上传图片或视频，填写标题、跳转入口和样式。图片最大 8MB，视频最大 30MB。
3. “保存共享草稿”保存到团队共享区。其他同事登录后读取同一份草稿。
4. “我的模板”保存团队共用模板，最多 20 套。
5. 需要先检查未发布内容时，点击“同步到开发版” → “检查连接” → “同步当前页面”。开发版首次连接时填写预览码，之后下拉刷新。
6. 对外更新商品时，先保存共享草稿，再点击“发布商城”。确认商品标题、图片、售价后发布。体验版、审核版和正式版自动读取这份已发布内容。

草稿保存、开发版预览和正式发布是三个独立步骤。保存与开发版同步不会改变正式内容。正式读取功能需使用本次更新的小程序代码（1.0.8）；旧版 1.0.7 不会自动获得代码改动。接入后，日常更换商品和图片只需保存并发布商城，不需要连接个人电脑或填写预览码。页面功能代码改变仍需要上传微信新版本。

同事已更新内容时，旧页面保存会被拒绝。先导出当前配置备份，再刷新读取最新内容，按需合并，避免覆盖。

## 会员中心（小程序 1.0.10 起）

后台左侧点击“会员中心”，独立编辑顶部海报、双列海报、横幅海报和积分商品。页面切换会保留当前未保存的编辑，退出或刷新前请先保存。

- 顶部海报与横幅没有二级页，可上传替换图片、调整高度或隐藏。
- 双列海报各自设置图片、标题和二级页开关；二级页可按顺序添加文字与图片。
- 积分商品支持添加、删除、排序、隐藏，以及编辑商品图片、标题、所需积分、商品介绍和兑换说明。当前“兑换”打开兑换说明，没有积分余额扣减或兑换订单功能。
- 点击“保存共享草稿”后再点击“发布会员中心”。正式发布不依赖电脑连接或首页预览码，首页与会员内容单独保存、单独发布。
- 点击“发布会员中心”会先列出所有未填写完整的已开启模块，包括左右海报、二级页和具体积分商品。“去编辑”可打开对应区域；补齐或关闭显示后，提示自动消失。未保存修改会提示先保存；网络超时、服务不可用或发布异常会在窗口内显示原因，可通过“重新检查”核对云端状态。
- 第一次使用需将含会员中心代码的 1.0.10 设为体验版并完成后续微信审核、发布。日常内容更新只需后台保存和发布会员中心。
- 未发布会员内容时，手机显示“会员活动即将上线”。请由运营上传正式素材、填写活动内容后发布；系统不会用虚构积分或测试商品填充。

会员草稿保存在 `topuyi_ops_content_v1/member_draft`，正式会员页保存在 `topuyi_storefront_live_v1/member_active`，发布历史为 `member_history_版本号`。上述记录与首页独立，权限沿用现有运营账号与云端私有集合。小程序只通过 `topuyi-storefront-v1` 的 `getMember` 读取已发布会员内容。

## 原本机草稿

在原电脑打开 http://localhost:5188/local ，导出原模板，再在在线后台导入；导入时会将素材上传到共享区，确认替换后点击保存草稿。

在线导出的 JSON 为配置备份，图片引用仅适用于本后台；请保留云端素材。原本机版导出的 JSON 包含图片和视频。

## 账号

首个管理员为 `topuyi_admin`，首个运营账号为 `topuyi_ops`。密码仅保存在本机 `.private` 目录中的登录说明，不随网站源代码提交和发布。

管理员可以使用本机维护脚本为每位同事开通独立账号：`node server/provision-operators.cjs 账号名称`。账号通过云开发官方认证；只有 `topuyi_operators_v1` 中有效的成员才有编辑权限。停用成员将对应记录的 `active` 设为 `false`，下一次访问接口即被拒绝。密码重置通过云开发用户管理执行，不在网页上暴露管理密钥。

## 数据范围

- 运营成员：`topuyi_operators_v1`，仅管理员访问。
- 共享草稿、模板、素材索引：`topuyi_ops_content_v1`，仅管理员访问。
- 开发版预览：`topuyi_home_preview_v1`。
- 正式页面及发布历史：`topuyi_storefront_live_v1`。
- 正式可购买商品：`topuyi_home_products_live_v1`。
- 本次在线素材：`topuyi/home-preview/v1/ops/`。
- 新增服务：`topuyi-ops-v1`，每次操作校验官方登录身份和成员权限。

网站服务端使用短期用户会话，Cookie 为 HttpOnly 和 SameSite，HTTPS 下启用 Secure。用户会话约两小时，过期后重新登录可继续当前未保存编辑。管理云密钥不进入网页或在线服务。

2026-09-13 已将现有共享草稿的 18 个商品发布到正式数据，读取服务为 `topuyi-storefront-v1`。结算从正式商品目录读取价格；开发预览与正式购物车分别保存。发布商品不修改支付商户配置，也不代替微信版本审核。
