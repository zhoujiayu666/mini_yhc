TOPUYI 周边商品 · 运营上架手册

在网页后台维护商品，无需找开发、无需重新发版小程序。
环境：云开发 cloud1-d4grfezxdaca540d6 · 小程序：TOPUYI拓普依

1. 怎么登录

  1. 向开发索取 云后台 / CMS 链接（微信开发者工具 → 云开发 → 云后台 → CMS 内容管理）
  2. 用 管理员微信扫码 登录
  3. 左侧菜单：内容管理 → 商品

2. 上架新商品（5 步）

步骤操作
①商品列表 → 新建
②填写下表必填项
③上传商品图、编辑详情（建议做）
④status 选 上架（on_sale）
⑤点 发布 / 保存

必填字段速查

字段填什么示例
sku商品编号（唯一）stick-01
name商品名称七彩荧光棒
price售价，单位：分1290 = ¥12.9
stock库存100
category分类（英文）stick 荧光棒 / ball 发光球
status上架状态（英文）on_sale 上架
sourceAppId固定值，每条都要填wx3610c3ef05d1131e

建议填写

字段说明
desc列表页短描述
images商品轮播图（可多图）
detailContent详情富文本
specs规格，每行一条
tag / sort角标 / 排序（越大越靠前）

3. 日常操作

要做的事怎么操作
改价编辑 → 改 price（分）→ 发布
换图编辑 images → 发布
下架status 改为 off_sale → 发布
重新上架status 改为 on_sale → 发布
置顶把 sort 调大 → 发布

6. 验收 & 检查单

手机打开小程序 → 周边 → 点商品看详情。刚改完没看到：关掉小程序重进（列表约 10 分钟缓存）。

  • status = on_sale
  • sourceAppId = wx3610c3ef05d1131e
  • price 按分填写
  • category 为 stick 或 ball
  • sku 未重复 · 已点发布

7. 常见问题

问题处理
看不到商品确认 status=on_sale；重进小程序
图片不显示确认图片已上传并发布
分类填错只能用 stick / ball
价格不对检查是否按「分」填写
日常流程：登录 CMS → 商品 → 编辑 → 发布 → 手机周边页验收
