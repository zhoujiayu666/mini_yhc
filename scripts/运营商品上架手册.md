# TOPUYI 周边商品 · 运营上架手册

> 在网页后台维护商品，**无需找开发、无需重新发版小程序**。  
> 环境：云开发 `cloud1-d4grfezxdaca540d6` · 小程序：TOPUYI拓普依

---

## 1. 怎么登录

1. 向开发索取 **云后台 / CMS** 链接（微信开发者工具 → 云开发 → 云后台 → CMS 内容管理）
2. 用 **管理员微信扫码** 登录
3. 左侧菜单：**内容管理** → **商品**

---

## 2. 上架新商品（5 步）

| 步骤 | 操作 |
|------|------|
| ① | 商品列表 → **新建** |
| ② | 填写下表必填项 |
| ③ | 上传商品图、编辑详情（可选但建议做） |
| ④ | `status` 选 **上架**（`on_sale`） |
| ⑤ | 点 **发布** / **保存** |

### 必填字段速查

| 字段 | 填什么 | 示例 |
|------|--------|------|
| **sku** | 商品编号（唯一，勿重复） | `stick-01` |
| **name** | 商品名称 | 七彩荧光棒 |
| **price** | 售价，单位：**分** | `1290` = ¥12.9 |
| **stock** | 库存 | `100` |
| **category** | 分类（英文） | `stick` 荧光棒 / `ball` 发光球 |
| **status** | 上架状态（英文） | `on_sale` 上架 |
| **sourceAppId** | 固定值，每条都要填 | `wx3610c3ef05d1131e` |

### 建议填写（提升展示效果）

| 字段 | 说明 |
|------|------|
| `desc` | 列表页短描述 |
| `images` | 商品轮播图（可多图） |
| `detailContent` | 详情富文本（图文） |
| `specs` | 规格，每行一条，如 `尺寸:20cm` |
| `tag` | 角标：热销、新品 |
| `sort` | 排序，数字越大越靠前 |
| `originalPrice` | 划线价（分），不填则无划线价 |

---

## 3. 日常操作

| 要做的事 | 怎么操作 |
|----------|----------|
| **改价** | 编辑商品 → 改 `price`（分）→ 发布 |
| **换图** | 编辑 `images` → 发布 |
| **改详情** | 编辑 `detailContent`、`specs` → 发布 |
| **下架** | `status` 改为 `off_sale` → 发布 |
| **重新上架** | `status` 改为 `on_sale`，确认有库存 → 发布 |
| **置顶** | 把 `sort` 调大 → 发布 |

---

## 4. 价格换算（重要）

| 想卖的价格 | price 填 |
|------------|----------|
| ¥0.01 | `1` |
| ¥12.9 | `1290` |
| ¥99 | `9900` |
| ¥199 | `19900` |

**公式：元 × 100 = price**

## 5. 规格 specs 示例

```text
尺寸:20cm
材质:PC+LED
电池:3节AAA
```

---

## 6. 怎么确认上架成功

1. 手机打开 **TOPUYI** 小程序
2. 底部 **周边** → 应能看到商品
3. 点击进入 **商品详情页** 检查图片和文案

**刚改完没看到？** 关掉小程序重新打开；列表有约 10 分钟缓存，详情页一般更快更新。

---

## 7. 上架前检查单（打勾再发布）

- [ ] `status` = **on_sale**
- [ ] `sourceAppId` = **wx3610c3ef05d1131e**
- [ ] `price` 按**分**填写
- [ ] `category` 为 **stick** 或 **ball**（英文）
- [ ] `sku` 未与已有商品重复
- [ ] 已点 **发布**

---

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| 小程序看不到商品 | 确认 `status=on_sale`；杀掉小程序重进 |
| 图片不显示 | 确认图片已上传并发布 |
| 分类填错 | 只能用 `stick` / `ball`，不能填中文 |
| 价格不对 | 检查是否按「分」填写 |

---

## 9. 联系开发的情况（少数）

以下情况再联系开发，**日常改商品不用**：

- CMS 打不开 / 无法登录
- 支付、下单异常
- 需要新增商品类型或页面功能

---

**日常流程一句话：** 登录 CMS → 商品 → 编辑 → 发布 → 手机周边页验收。
