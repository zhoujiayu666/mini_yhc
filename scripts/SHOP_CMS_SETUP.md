## 一、开通内容管理（CMS）

1. 打开微信开发者工具 → **云开发** → 进入控制台  
2. 左侧 **扩展能力** → **内容管理**（或「CMS」）  
3. 按提示 **开通**（首次需管理员扫码）  
4. 进入 CMS 后台地址（控制台会显示链接，用管理员微信扫码登录）

---

## 二、创建「商品」内容模型

在 CMS 后台 → **内容模型** → **新建模型**：

| 配置项 | 填写 |
|--------|------|
| 模型名称 | 商品 |
| 标识 / API 名 | `product`（系统生成即可） |
| **关联集合** | `products`（与现有云数据库集合一致） |

> 若已有 `products` 数据，选择「关联已有集合」；字段名须与下表一致。

### 字段列表（按此添加）

| 字段名 | CMS 类型 | 必填 | 说明 |
|--------|----------|------|------|
| `sku` | 单行文本 | 是 | 商品编号，唯一，如 `stick-01` |
| `name` | 单行文本 | 是 | 商品名称 |
| `desc` | 多行文本 | 否 | 列表页短描述 |
| `price` | 数字 | 是 | **单位：分**，1290 = ¥12.9 |
| `originalPrice` | 数字 | 否 | 划线价（分），0 或不填表示无划线价 |
| `category` | 枚举/单行文本 | 是 | `stick` 荧光棒 / `ball` 发光球 |
| `color` | 单行文本 | 否 | 无图时的展示色，如 `#39FF14` |
| `images` | **图片**（多图） | 否 | 商品轮播图，可直接上传 |
| `specs` | 多行文本 | 否 | 规格，见下方格式 |
| `detailContent` | **富文本** | 否 | 详情长文（图文混排） |
| `tag` | 单行文本 | 否 | 角标：热销、新品等 |
| `stock` | 数字 | 是 | 库存 |
| `sort` | 数字 | 否 | 排序，越大越靠前 |
| `status` | 枚举 | 是 | `on_sale` 上架 / `off_sale` 下架 |
| `sourceAppId` | 单行文本 | 是 | 固定填 `wx3610c3ef05d1131e` |

系统字段 `createdAt` / `updatedAt` 可由 CMS 或云函数自动维护；新建时 `sourceAppId` 务必正确。

## 三、规格 `specs` 怎么填（给运营）

在 CMS **多行文本** 里，每行一条，格式：

```text
尺寸:20cm
材质:PC+LED
电池:3节AAA
```

也支持竖线分隔：`尺寸|20cm`

## 四、发布商品

1. CMS → **内容列表** → **商品** → **新建**  
2. 填写字段、上传多图、编辑富文本详情  
3. 点击 **发布**（或保存为已发布状态）  
4. 手机打开周边页 → 点商品进入 **商品详情页** 查看

无需重新上传小程序（仅改图文时）。

## 七、常见问题

**Q：CMS 改了，小程序没变？**  
A：周边列表有 10 分钟本地缓存；进详情页会拉最新。可杀掉小程序重进。

**Q：图片不显示？**  
A：确认 CMS 图片已发布；`images` 字段存的是云存储地址（`cloud://` 或 https）。

**Q：富文本样式乱？**  
A：微信 `rich-text` 仅支持部分 HTML 标签，CMS 里避免复杂 CSS。

**Q：和种子数据冲突？**  
A：首次 `products` 为空时云函数会自动 seed；之后以 CMS 数据为准，直接在 CMS 编辑即可。
