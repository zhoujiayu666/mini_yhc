# 周边商城 Phase 1 部署说明

> 能力：云商品、购物车、收货地址、提交订单（待付款）、我的订单。  
> **不含**微信支付（需商户号后接 Phase 2）。

---

## 步骤 1：创建数据库集合（约 3 分钟）

云开发控制台 → **数据库** → 新建集合：

| 集合 | 权限建议 |
|------|----------|
| `products` | 仅管理端可读写 |
| `orders` | 仅管理端可读写 |
| `addresses` | 仅管理端可读写 |

---

## 步骤 2：部署云函数（约 3 分钟）

1. 确认 `cloudfunctions` 已绑定云环境 `cloud1-d4grfezxdaca540d6`
2. 右键 **`shop-service`** → **上传并部署：云端安装依赖**

首次打开周边页时，云函数会自动写入 8 个种子商品（若 `products` 为空）。

也可在云端测试手动导入：

```json
{ "action": "seedProducts" }
```

---

## 步骤 3：小程序冒烟（约 10 分钟）

- [ ] **周边**页：商品列表正常（非仅本地兜底）
- [ ] 加入购物车 → 购物车图标数量增加
- [ ] **立即购买** / 去结算 → 确认订单页
- [ ] **我的** → 收货地址 → 新增地址
- [ ] 提交订单成功 → 订单详情「待付款」
- [ ] **我的** → 我的订单 → 能看到刚下的单
- [ ] 待付款订单可取消

---

## 步骤 4：手动发货（运营，无开发）

用户付款功能开通前，订单会停在 `pending_pay`。若需测试发货流程，可在控制台把订单 `status` 改为 `shipped`，并填写：

- `trackingNo`：快递单号
- `expressCompany`：快递公司
- `shippedAt`：发货时间戳

用户在订单详情可「确认收货」。

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 周边页无法加购 | 部署 `shop-service`，创建三个集合 |
| `shop-service 未部署` | 同群控，检查云环境绑定 |
| 商品列表是本地数据 | 云函数未通；看控制台 `[around] 云商品加载失败` |
| 提交订单失败 | 检查地址是否填写；库存是否充足 |
| 「去支付」不可用 | 正常，等微信支付商户号 |
